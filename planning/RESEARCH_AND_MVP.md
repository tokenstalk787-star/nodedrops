# NodeDrops.xyz — Research and MVP Scope

## Research Date
2026-10-22

## Platforms Reviewed

### Ethereum.org
Official node and client documentation.
Reference:
https://ethereum.org/developers/docs/nodes-and-clients/

Research note:
Ethereum node guides must explain execution and consensus
clients, setup requirements, synchronization, verification,
security and maintenance.

### Dappnode
Node deployment and management platform.
Reference:
https://docs.dappnode.io/

Research note:
Guided setup and node management are established solutions.
NodeDrops will focus on cross-network educational guides.

### Chainstack Self-Hosted
Node deployment and operations platform.
Reference:
https://chainstack.com/self-hosted/

Research note:
Monitoring, upgrades and recovery are important operational
topics for advanced guides.

### Solana Documentation
Official cluster documentation:
https://solana.com/docs/references/clusters

Official RPC documentation:
https://solana.com/docs/rpc

Research note:
Devnet, Testnet and Mainnet have different purposes.
Public RPC endpoints have limitations and are not automatically
suitable for production applications.

## Proposed Differentiation
- Cross-network node guide directory
- Testnet and mainnet comparison
- Step-by-step commands and expected outputs
- Hardware and cost estimates with dated assumptions
- Source-reviewed versus setup-tested statuses
- Troubleshooting and security guidance
- Evidence-based incentive information

## MVP Features
1. Homepage and global search
2. Testnet and mainnet directories
3. Network detail pages
4. Node-type and installation guides
5. Guide categories and difficulty levels
6. Hardware and cost information
7. Source references and verification records
8. Secure admin publishing
9. Responsive layout and SEO
10. Production deployment and basic analytics

## Initial Research Candidates
- Ethereum testnet node setup
- EVM development node guide
- Solana Devnet and Testnet guidance
- Mainnet node types and operational requirements

These are candidates, not yet verified or published guides.

## Out of Scope for Initial Release
- Automatic installation on user servers
- Collection of private keys or seed phrases
- Automated staking or financial transactions
- Guaranteed airdrop or token reward claims
- Full monitoring and alerting infrastructure
- Public user-generated guides without review

## MVP Acceptance Criteria
- All core routes function
- Search and filters return correct results
- Guides are stored and served through the database
- Admin routes enforce authorization
- Verification statuses are accurate
- Automated checks and production build pass
- Mobile and desktop layouts work
- Domain and HTTPS are configured

## Research Limitations
This is an initial qualitative review, not a complete
competitor audit or quantitative market analysis.
Requirements and documentation must be rechecked before
publishing individual node installation guides.
