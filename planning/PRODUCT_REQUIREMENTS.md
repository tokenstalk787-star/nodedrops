# NodeDrops.xyz — Product Requirements

## Product Vision
A reliable platform for step-by-step blockchain node deployment,
operation, verification, and troubleshooting guides.

## Target Users
- Beginners learning blockchain infrastructure
- Developers running testnet and devnet nodes
- Operators maintaining production mainnet nodes

## Core Features
1. Searchable network directory
2. Testnet and mainnet categories
3. Individual network and node-type pages
4. Step-by-step installation guides
5. Copyable commands and expected outputs
6. Hardware and cost estimates
7. Troubleshooting and security guidance
8. Official source links and verification dates
9. Admin content management
10. Responsive design and SEO

## Initial Release
- Public website
- Network and guide directories
- Guide detail pages
- Search and filtering
- MySQL database
- Secure admin publishing
- Testing and production deployment

## Quality Requirements
- Never invent rewards or hardware requirements
- Distinguish source-reviewed from practically tested guides
- Show supported software versions and verification dates
- Never request users' private keys
- Do not execute installation commands on users' servers
- Document mainnet risks clearly

## Initial Technology Proposal
- Next.js
- TypeScript
- Tailwind CSS
- MySQL
- Prisma ORM
- GitHub
- Vercel

## Launch Criteria
- All essential routes work
- Database operations are tested
- Production build passes
- Mobile and desktop layouts are verified
- Official source links are checked
- Domain and HTTPS are configured
